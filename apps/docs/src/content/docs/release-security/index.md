---
title: Release & security
description: BeeUI's release process and how to report vulnerabilities.
---

Report security issues privately per the repository's `SECURITY.md` — do not open a
public issue for a vulnerability. `CONTRIBUTING.md` documents local setup, required
gates, and BeeUI's architecture invariants.

:::caution[Pre-1.0 status]
BeeUI packages and the CLI remain unpublished (`private: true`, no npm publication, no
`v1.0.0` tag). The repository itself remains private by explicit owner decision.
Release-ready is not the same as released.
:::
